### New
- **Coach: feedback on your singing** (new tab). Analyse the last take, or any recording (WAV, MP3, M4A, FLAC), without the program knowing the song.
  - Strengths first, then the most important problems with timestamps and a likely cause for each, the exercises to fix them, and a 5–10 minute daily practice plan.
  - Measures pitch accuracy per note and per pitch zone, sharp/flat tendency, the key and notes outside it, a vocal shifted against the music, scoops, wandering notes, falling phrase endings, vibrato, tone (HNR, CPP, jitter, shimmer), cracks, dynamics and range.
  - Graphs, export to HTML, and a history that compares each take with the previous one.
  - English by default, with Thai as an option.
  - **Get feedback** in the review window opens it straight after recording.
- Releases are now built by GitHub Actions from the tagged source, with a SHA-256 checksum and a build-provenance attestation.
